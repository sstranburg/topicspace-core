# Storm Detection System

Event clustering and tracking for tech ecosystem actors.

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your API keys
```

## Structure

- `src/` - Core modules
- `scripts/` - Runnable scripts
- `data/normalized/` - Normalized JSONL events
- `data/derived/` - Embeddings and storm outputs
- `tests/` - Test scripts
